# Images Directory

## Background Image

**Required:** Place your `background.jpg` file in this directory.

### Specifications:
- **Filename:** `background.jpg`
- **Format:** JPG/JPEG
- **Recommended Size:** 1920x1080 or larger
- **Content:** Blue grid pattern (professional technical/electrical theme)
- **Optimization:** Compress to ~200-500KB for optimal performance

### Purpose:
The background image creates a professional grid pattern visible through:
- Transparent header with backdrop blur
- Semi-transparent content sections
- Card elements with frosted glass effect

### Notes:
- The background uses `background-attachment: fixed` on desktop
- Mobile uses `background-attachment: scroll` for better performance
- Backdrop blur effects provide readability without sacrificing design
